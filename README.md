# Ishkant Sharma — Personal Portfolio

A modern, responsive personal portfolio website showcasing my background, technical skills, selected projects, and contact information.

## Features

- **Responsive design** for desktop and mobile screens
- **Animated typewriter text** highlighting the things I build
- **Interactive mobile navigation** with an expandable menu
- **Animated particle background** with connected particles
- **Scroll-reveal effects** for sections and skill cards
- **Animated skill progress bars**
- **Projects showcase** featuring software and hardware work
- **Resume download section**
- **Contact section** with email and social profile links

## Built With

- **HTML5** — page structure and content
- **CSS3** — layout, styling, responsive design, and animations
- **JavaScript** — typewriter effect, mobile menu, particle animation, and scroll interactions

## Run Locally

1. Clone or download this repository.
2. Open the project folder.
3. Make sure `index.html`, `style.css`, and `script.js` are in the correct locations.
4. Add your profile image to `assets/hero-profile.png` and your resume as `resume.pdf`, or update the paths in the HTML.
5. Open `index.html` in your browser.

## Website Sections

- **Home** — introduction and animated headline
- **About Me** — background and approach to learning
- **Skills** — HTML, CSS, JavaScript, C/C++, and SQL/MySQL
- **Projects** — selected hardware and software projects
- **Resume** — downloadable resume
- **Contact** — email and professional links

## Accessibility & Motion

The site includes accessible labels for the mobile navigation and uses the `prefers-reduced-motion` media preference to limit the particle animation when reduced motion is requested. Continue testing keyboard navigation, contrast, and screen-reader behavior as the project evolves.
